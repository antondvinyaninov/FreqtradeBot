# Развёртывание dry-run в Easypanel

## Что будет запущено

Один контейнер Freqtrade в `dry_run` с `TrainingStrategy`. Контейнер не содержит ключей биржи, не отправляет реальные ордера и не открывает сетевые порты. Состояние SQLite и логи сохраняются в Docker-томах Easypanel.

## Подготовка репозитория

Easypanel должен получить исходный код из отдельного личного или приватного Git-репозитория. Нельзя подключать напрямую `freqtrade/freqtrade`: в нём нет наших локальных настроек и стратегии.

## Настройка сервиса

1. В проекте Easypanel выберите `Compose`.
2. Подключите личный Git-репозиторий с этим проектом.
3. Укажите файл `deployment/easypanel.compose.yml`.
4. Не добавляйте переменные с ключами биржи.
5. Нажмите Deploy и дождитесь статуса `Running`.

## Проверка после запуска

Логи должны содержать строки `Dry run is enabled`, `Strategy: TrainingStrategy` и `Changing state to: RUNNING`.

## Доступ и безопасность

На этом этапе Web UI выключен намеренно. Для наблюдения используйте логи Easypanel. API и внешний порт добавляются только после отдельной настройки аутентификации и закрытого способа доступа.
