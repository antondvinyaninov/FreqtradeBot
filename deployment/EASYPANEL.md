# Развёртывание dry-run в Easypanel

## Что будет запущено

Один контейнер Freqtrade в `dry_run` с `TrainingStrategy`. Контейнер не содержит ключей биржи, не отправляет реальные ордера и не открывает сетевые порты. История сделок хранится в PostgreSQL, а логи сохраняются в Docker-томе Easypanel.

## Подготовка репозитория

Easypanel должен получить исходный код из отдельного личного или приватного Git-репозитория. Нельзя подключать напрямую `freqtrade/freqtrade`: в нём нет наших локальных настроек и стратегии.

## Настройка сервиса

1. В проекте Easypanel создайте сервис `Приложение`.
2. Подключите личный Git-репозиторий с этим проектом.
3. Укажите файл `Dockerfile.server`.
4. В разделе `Окружение` добавьте `FREQTRADE__DB_URL` со значением внутреннего URL PostgreSQL, начиная его с `postgresql+psycopg://`.
5. Не добавляйте переменные с ключами биржи.
6. Нажмите Deploy и дождитесь статуса `Running`.

## Проверка после запуска

Логи должны содержать строки `Dry run is enabled`, `Strategy: TrainingStrategy` и `Changing state to: RUNNING`.

## Доступ и безопасность

На этом этапе Web UI выключен намеренно. Для наблюдения используйте логи Easypanel. API и внешний порт добавляются только после отдельной настройки аутентификации и закрытого способа доступа.
